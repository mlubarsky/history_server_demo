HOW TO RUN V1
==================================================================

FIRST TIME ONLY
---------------
1. Install dependencies:
      pip3 install streamlit altair pandas

2. Download the NYC taxi data (~150 MB):
      ./download_data.sh

3. Run all 5 Spark jobs to generate event logs (takes a few minutes):
      ./run_all_jobs.sh
      Job 05 is slow on purpose -- that's the point of the demo.


EVERY TIME AFTER THAT
---------------------
Open two terminal tabs:

  Tab 1 -- start the history server (must come first, GUI reads from it):
      ./start_history_server.sh

  Tab 2 -- start the dashboard GUI:
      python3 -m streamlit run dashboard.py

  Then open: http://localhost:8501


WHAT YOU'LL SEE
---------------
- "Compare apps" tab: bar chart + table comparing all 5 jobs side by side.
  Switch metrics (wall time, shuffle, tasks, etc.) with the buttons at the top.
  Job 05 will be the biggest bar on almost every metric -- it's written badly on purpose.

- "App detail" tab: pick one job from the dropdown.
  Shows headline numbers, a stage timeline, the jobs table, and any skewed stages.


WHEN YOU'RE DONE
----------------
  Ctrl+C          (stops the dashboard)
  ./stop_history_server.sh


NOTES
-----
- If you run a new job and don't see it in the GUI, click Refresh in the sidebar.
- The GUI caches data for 60 seconds, so it may take a moment to update.
- Job 04 intentionally fails at the end -- that's expected, not a bug.
- Raw API data is saved to history_dump/ each time analyze_history.py runs.
